# 📌 Projeto de Estruturação e Automação em Python para Análise de Dados

## 📖 Objetivo

Este projeto foi criado com o objetivo de praticar a organização de código em projetos de análise de dados utilizando Python.

A proposta é separar funções reutilizáveis em módulos `.py`, mantendo os notebooks mais limpos, organizados e focados apenas na análise, visualização e interpretação dos dados.

Além disso, o projeto busca simular uma estrutura mais próxima do ambiente profissional, priorizando:

- reutilização de código
- modularização
- automação
- legibilidade
- manutenção
- escalabilidade

---

# 🛠 Tecnologias Utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

# 📊 Sobre os Notebooks

Os notebooks possuem foco exclusivamente em:

- análise exploratória
- visualização de dados
- interpretação dos resultados
- storytelling

Toda lógica auxiliar e funções repetitivas são armazenadas na pasta `src/`.

---

# 💡 Motivação

Em muitos projetos de análise de dados, é comum concentrar toda a lógica dentro de notebooks, o que pode dificultar:

- manutenção
- reutilização
- escalabilidade
- organização do projeto

Este repositório foi criado justamente para praticar uma abordagem mais estruturada e profissional no desenvolvimento de projetos com Python.
